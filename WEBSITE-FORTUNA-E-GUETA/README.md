# Clínica Fortuna e Gueta | Landing Page

Landing page de serviços da **Clínica Fortuna e Gueta**, criada para apresentar
de forma clara e profissional os serviços clínicos oferecidos aos pacientes.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Apresentação dos serviços clínicos
- Design responsivo (telemóvel, tablet e computador)
- Vídeo de apresentação
- Agendamento de Consulta
- Geração de PDF no processo de agendamento da consulta
- Dados guardado pelo google sheet
- Contactos da clínica

## Estrutura do projeto

├── index.html
├── css/
├── js/
└── Assets/
├── img/
└── video/


## Como executar localmente
1. Faz o download ou clona o repositório:
   `git clone https://github.com/PauloKiangalaNgonga/WEBSITE-FORTUNA-E-GUETA.git`
2. Abre o ficheiro `index.html` no navegador.

## Publicação
O site é publicado na Vercel. Cada `git push` para o branch `main`
atualiza automaticamente a versão online.
